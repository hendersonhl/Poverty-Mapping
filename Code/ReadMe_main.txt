The codes in this repository reproduce the results for "Poverty Mapping in the Age of Machine Learning"
The data used is the 2015 Mexican Intercensal survey produced by INEGI. It has been cleaned and modified as described
in Corral, Himelein, McGee, and Molina (2021). The process for drawing 500 representative samples from 
the intercensal survey is described in that same document. There are individual ReadMe files in the relevant
folders.

- Codes are split by function:
	- Traditional SAE folder: Codes for unit and area level estimates.
	- Python and R codes for ML models: Codes for ML based estimates.
	- Targeting simulation: Codes for reproducing the cash transfer targeting simulation.
	- Produce results: Codes for producing results and figures presented in the paper.

* Codes must be run in the order detailed above.
